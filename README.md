# 校园跑腿互助平台 Campus Errand

> **🌐 在线体验（公开访问）**
>
> **[https://mingzior.github.io/campus-errand-platform/](https://mingzior.github.io/campus-errand-platform/)**
>
> 网站通过 GitHub Pages 免费托管。仓库为公开仓库，任何人均可直接打开上方链接访问，无需登录 GitHub 或申请权限。

校园场景的跑腿互助平台概念项目，目标是帮助学生发布和承接日常小任务，并通过订单记录与信用机制建立可信赖的互助社区。

## 当前版本：V0.2 交互原型

已实现以下前端交互（仅保存在访问者自己的浏览器中）：

- 按关键词、任务类别和区域筛选任务
- 查看任务详情、截止时间、预计耗时与报酬
- 发布任务表单及必填项、时间、报酬和部分风险词校验
- 模拟接单、申请确认、提交完成、确认完成、取消和争议流程
- 查看“我的任务”与本地履约事件记录
- 模拟举报入口
- 使用浏览器 localStorage 保存本机演示数据，刷新后通常仍可查看

> **重要边界：** 当前尚未接入真实后端。任务和操作只存储在当前浏览器，不会同步给其他访问者；模拟举报不会发送给审核人员；没有真实账号、校园身份认证、服务端订单、支付或消息通知。请勿输入真实联系方式、学号、精确住址或其他敏感信息。页面不是可处理真实交易的平台。

## 后端接入路线

后端目前处于准备阶段。建议先完成 Supabase 项目配置、数据库与 RLS 策略审查，再逐步实现账号认证、服务端任务持久化、原子接单、订单状态机和私有举报工单。部署所需的项目 URL 与公开客户端 key 尚未配置；绝不能将 service-role key 或数据库密码写入公开前端。
